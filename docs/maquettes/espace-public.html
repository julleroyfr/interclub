Correspondance maquettes → règles (spec #8)

Écran 1 — Liste publique

  • R1/R2 — routes /rencontres (liste) et /rencontres/[id] (détail), sans authentification, lecture seule. Accès « Se connecter » conservé.
  • R3 — toutes les rencontres, date décroissante (à venir en tête, puis passées) ; liste continue.
  • R4/R5/R6 — date + club d'accueil toujours ; compteurs (clubs/équipes/grimpeurs) dès les engagements ; badge d'état.

Écran 2 — À venir ①

  • R5 — pré-compétition : date + club d'accueil uniquement ; ni compteurs, ni résultats.

Écran 3 — En cours ②/③/④ (non publiée)

  • R6 — date + accueil + compteurs, mais aucun résultat ni classement pour le public.
  • R8/R11 — aucun résultat nominatif public avant la ⑤ ; les authentifiés (clubs), eux, suivent au fil de l'eau (spec #1 R8).

Écran 4 — Publiée ⑤

  • R7/R9 — classement individuel Filles / Garçons (spec #7 R8b) + par équipe ; pas de classement par club.
  • R10 — rang / libellé / score, marqués ✓ Officiel (la ⑤ fige, spec #1 R8) ; longues listes → recherche + pagination en bas (spec #7 R12b).

Sécurité (R11 / Contraintes de données) : pages rendues côté serveur (service_role), gating par état dans le loader — aucune policy RLS ouverte à anon, donc aucun résultat exposé avant la ⑤, quel que soit le chemin d'accès.
