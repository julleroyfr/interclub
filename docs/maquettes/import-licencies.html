Correspondance maquette → règles (spec #13)

Formulaire

  • Dépôt .xlsx (R3) — un seul fichier ; lecture 1re feuille, colonnes par position A→F (R4).
  • Année de référence (R6) — calculée automatiquement (année de fin de saison courante, anneeSaison(aujourd'hui)+1), non modifiable ; seuil d'âge = année − 18 (R7).
  • Réservé à l'admin (R1) ; route /admin/grimpeurs/import (R2).

Compte-rendu (R18)

  • Compteurs créés / mis à jour / ignorés (hors âge) / erreurs (R8, R13, R17).
  • Clubs créés automatiquement par nom (R11–R12).
  • Lignes en erreur avec n° de ligne + raison (R10) ; doublons internes signalés (R14).
