Correspondance maquette → règles & décisions

Responsive (l'objet de cette version)

  • Desktop (≥ 1024 px) — maître-détail deux colonnes : liste 380px + saisie 1fr ; dans le détail, voies et blocs côte à côte. L'écran occupe la largeur (min(1240px, 100%)), pas de largeur figée.
  • Mobile / tablette (< 1024 px) — repli en une colonne : la liste puis le détail s'empilent ; cibles tactiles ≥ 44 px, champ de recherche à 16 px (anti-zoom iOS). Mobile-first : styles de base sans préfixe, colonnes ajoutées via @media (min-width:1024px).
  • Le grimpeur sélectionné reste en évidence dans la liste (bord rose) ; « Grimpeur suivant » enchaîne sans revenir à la liste.

Périmètre (à acter en spec)

  • Décision produit — l'admin saisit/modifie tout grimpeur, tous clubs, dès la ③ (et corrige en ④). Étend spec #6 R1 et spec #1 R6.
  • Motivation : club sans coach présent, saisie déléguée, correction.

Réutilise l'existant

  • Lecture cross-club : assemblage service_role déjà en place (classement, ADR 0002/0003).
  • Écriture : la RLS resultat_* autorise déjà l'admin (branche est_admin() des policies insert/update) ; sélecteur d'issue et cohérence catégorie/type identiques au coach (spec #6 R8/R10/R12, trigger BDD).
  • Point d'entrée : action « Saisir / corriger les résultats » sur /admin/rencontres/[id] → nouvelle route /admin/rencontres/[id]/resultats.
