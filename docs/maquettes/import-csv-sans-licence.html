Correspondance maquette → règles (spec #18)

Formulaire

  • Club cible obligatoire (R3) ; route /admin/grimpeurs/import-csv, lien depuis l'import FFME (R2) ; admin seul (R1).
  • Dépôt .csv (R4) ; UTF-8, virgule ou point-virgule (R5) ; en-têtes contrôlés (R6).
  • Filtre d'âge identique à l'import FFME (R11).

Compte-rendu (R17)

  • Compteurs créés / déjà présents / ignorés / erreurs ; doublons du fichier (R12).
  • Erreurs : champ invalide (R8, R10), caractère illisible (R8b), rapprochement ambigu (R13).

Écran Grimpeurs

  • Licence de la plage réservée suivie de la mention « générée » (R14–R15, spec #3 R21c/R26).
